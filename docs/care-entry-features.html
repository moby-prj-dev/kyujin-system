1 求職者向け機能

求人検索・閲覧

  • 沖縄全体・エリア別の求人一覧（/jobs/okinawa、/jobs/okinawa/{slug}）
  • エリア / 職種 / 雇用形態 / 勤務条件 / 重視ポイントによる複合絞り込み
  • 求人LPページ（/lp/{token}）— トークンベースの個別求人ページ、ログイン不要
  • AIが自動生成したタイトル・サブタイトル・タグ・本文・メタディスクリプションを表示
  • SEOメタデータ自動設定（OGP含む）

フォーム応募

  • ステップ式応募フロー（ステップ1：募集要項確認・条件選択 → ステップ2：応募者情報入力）
  • 応募前に求人条件と希望条件のマッチング判定を実施
  • 自動無効判定（重複応募・スパム・テスト投稿の検出）
  • 応募完了サンクスページ表示
  • レート制限：60秒内10回まで

LINE応募・連携

  • LINE LIFF応募（/liff/{token}）— LINEアプリ内での応募フロー、LINE IDと表示名を自動取得
  • LINE Webhook対応（/webhook/line）— LINEからの会話型応募フロー
  • チャットセッション管理（CONFIRMING → COLLECTING_NAME → COLLECTING_PHONE の段階的情報収集）
  • 条件不一致時の他求人自動提案
  • Webhook署名検証によるセキュリティ確保

お役立ち記事

  • SEO記事一覧・詳細ページ（/articles、/articles/{slug}）
  • カテゴリ：業界情報 / 職種別 / エリア情報 / 資格・研修 / 未経験・転職

  • 確認メール再送機能
  • 同一メール・電話での重複掲載チェック（複製警告画面あり）

求人管理画面（/jobs/{token}）

  • 求人情報の編集（全項目）
  • 掲載ステータス表示（公開中 / 一時停止 / 期限切れ / 終了）
  • 公開中求人URLのワンクリックコピー
  • 無料掲載期間・残り日数の表示
  • 応募件数（総数 / 有効 / 無効 / 無料枠残数）の表示
  • 応募者一覧（氏名・連絡先・応募種別・有効性・課金対象）
  • 掲載継続・一時停止・再開・完全削除の操作
  • 請求情報の確認（月次請求額・ステータス・応募明細）

求人複製

4 システム・バックエンド機能

AI・自動生成

  • 求人SEOコンテンツ自動生成（SeoGeneratorService）— エリア・職種・条件からタイトル・サブタイトル・タグ・本文を生成、スコアベースで主訴求を決定
  • 記事自動生成（ArticleGeneratorService）— Artisanコマンドで11種のテンプレートから記事を一括生成

メール通知

メール種別送信タイミング宛先
JobVerificationMail求人作成時のメール認証掲載主
AdminJobNotificationMail求人公開時管理者
JobManageLinkMail管理リンク再送時掲載主
応募通知（LINE/フォーム）応募発生時掲載主
TrialEndingWarningMail無料期間終了3日前掲載主
JobExpiredMail求人有効期限切れ時掲載主
JobContinuedMail求人継続操作時掲載主
BillingSummaryMail月次請求送信時掲載主

課金・試用管理

  • 無料枠：有効応募3件まで無料（会社単位で集計）
  • モニター期間：3か月間または有効応募3件まで無料（設定から動的管理）
  • 課金単価：有効応募1件 = ¥3,000（税別）
  • 未払い・期限超過企業の新規掲載ブロック
  • BillingService による月次集計・自動請求生成

応募検証（ApplicationValidationService）

  • 必須項目チェック（氏名・電話またはメール）
  • テスト投稿検出（test / テスト / あああ 等）
  • スパム検出（spam / bot / noreply 等）
  • 重複応募ブロック（同一求人・同一メール/電話）
  • 電話番号・メールアドレスの正規化（全角→半角、ハイフン除去）

定期実行コマンド（Artisan）

  • billing:generate-monthly — 前月の有効応募を集計して月次請求生成・メール送信
  • billing:send-trial-warnings — 無料期間終了3日前の警告メール送信（重複送信防止付き）
  • jobs:send-expired-notifications — 期限切れ求人の通知送信
  • articles:generate-content — 定義済みテンプレートからSEO記事を一括生成

セキュリティ

  • レート制限：求人作成（5回/60秒）・応募確認（20回/60秒）・応募送信（10回/60秒）
  • LINE Webhook 署名検証（X-Line-Signature）
  • 管理者操作の AuditLog 記録（アクション・モデル・変更内容・IPアドレス）
  • トークンベース認証（32文字ランダム、ログイン不要で求人管理）
