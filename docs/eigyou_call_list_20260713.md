## 📞 電話トーク基本形

```
「お世話になっております。沖縄・介護福祉に特化した求人サイト
 Care Entry の岸本と申します。恐れ入ります、
 求人採用のご担当者様、または経営者様はいらっしゃいますか?」

(取り次いでもらえたら)

「実は御施設の求人、うちの Care Entry で既に無料で掲載中でして、
 6月には Google 検索で○○回表示されているんですが、
 電話番号とメールを追加するだけで、直接応募が受けられる形にできます。
 掲載費は0円、応募が来た時だけ 3,000円 のご請求です。
 いま無料モニターキャンペーンで、3ヶ月間 or 有効応募3件までは
 その 3,000円 も無料になります。5分程度ですがお時間ありますか?」
```

**キーポイント:**
- 「経営者様」と最初に聞く=施設長=決裁者
- 「既に無料で載ってる」で興味を引く
- 「電話とメール追加だけ」で心理ハードル下げる
- 「無料モニター」で試す動機
